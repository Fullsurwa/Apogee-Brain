# Contributing

This repository is a preservation and packaging repository for the current Apogee SKOPE / Apogee Brain working system.

## Scope

Contributions should not redesign the application, refactor the working runtime, or change established behavior.

The public repository is intended to:

- document the current architecture
- preserve the useful working setup
- make onboarding and configuration clearer
- avoid exposing private data and secrets

## Before contributing

- do not commit .env files
- do not add credentials or tokens
- do not include local-only vault data or personal paths
- do not modify the working runtime behavior without a clear reason
- do not publish private archives or local machine state

## Pull requests

PRs should be small, focused, and explain clearly what is being documented or configured. Prefer changes that improve GitHub readiness without altering the live runtime system.
